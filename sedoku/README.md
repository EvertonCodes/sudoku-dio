# Sudoku DIO - Projeto Prático

Este projeto é uma implementação do jogo Sudoku baseada no repositório da DIO, incluindo versão terminal e interface gráfica.

## 🔹 Funcionalidades
- Jogo Sudoku no terminal
- Interface gráfica opcional
- Entrada de argumentos para definir células fixas e preenchíveis

## 🔹 Execução
Para rodar o Sudoku no terminal, use:

```bash
java -cp bin SudokuApp "0,0;4,false 1,0;7,false 2,0;9,true ..."
